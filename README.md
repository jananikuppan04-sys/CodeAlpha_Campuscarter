# CampusCart 🛒

A modern e-commerce platform for campus essentials built with Node.js, Express, and vanilla JavaScript.
link: https://campuscart.fly.dev/

## Features

- 🛍️ Product browsing and details
- 🛒 Shopping cart functionality
- 👤 User registration and login
- 📦 Order processing
- 🎨 Modern, responsive UI

## Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/campuscart.git
cd campuscart
```

2. Install dependencies:
```bash
npm install
```

3. Start the server:
```bash
npm start
```

4. Open your browser and visit:
```
http://localhost:3000
```
